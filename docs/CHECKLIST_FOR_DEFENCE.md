## Практические шаги для команды

1. Скопировать рабочий код `src/`, `tests/`, `data/external/` (особенно чистый CSV и кэш, если нужна полная воспроизводимость) из исходного проекта vacv-si в этот каркас.
2. Убедиться, что файл `outputs_v2/submission.csv` присутствует (или перегенерировать его).
3. В конце README.md указать **точное название команды**, которое полностью совпадает с названием на Kaggle.
4. Запушить в публичный GitHub-репозиторий.
5. Отправить ссылку через форму Яндекса до 09:30 8 ноября.
6. **Не вносить изменения** в репозиторий после дедлайна.

## Важные напоминания

- Название команды на Kaggle должно полностью совпадать с названием при регистрации на хакатон.
- Не использовать скрытые колонки из test.csv.
- Поправка по аналогам должна оставаться под контролем CV (как реализовано в v2).
- Публичный балл сильно зависит от нескольких экстремальных значений SI; на приватном лидерборде порядок мест может измениться.
