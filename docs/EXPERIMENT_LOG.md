# Лог экспериментов (восстановлен по истории разработки)

Документ суммирует итеративный процесс, который привёл к финальному решению v2. Основан на рабочих заметках и промежуточных результатах, полученных во время соревнования.

## Обзор этапов

### Начальный каркас
- Скелет репозитория, набор тестов, офлайн/fallback-режим (без RDKit, без сети).
- 18 → 26 → 32 юнит-теста, покрывающих защиту данных, генерацию признаков и путь обучения.
- Запасные признаки (без RDKit) дали Spearman ≈ 0.81 и обрезанную MSE ≈ 100k (против 127k у константного прогноза) на случайных фолдах.

### Устойчивость сбора данных
- Первый полный прогон ChEMBL завис на документе №199 (очень большая таблица активностей + длинные таймауты).
- Добавлено:
  - фильтр по типам активностей,
  - таймаут на документ (300 с) и лимит размера (50 тыс. активностей),
  - автоматический пропуск + `skipped_docs.csv`,
  - полный кэш ответов,
  - промежуточные сохранения каждые 20 документов,
  - логирование прогресса.
- Многие документы после фильтрации дают 0 строк (ожидаемо — в старых работах часто указаны MIC / % ингибирования, а не IC50/EC50).

### Модель v1
- Ансамбль: ExtraTrees + RandomForest + HistGradientBoosting + Tanimoto-SVR.
- Признаки: Morgan-счётчики + дескрипторы RDKit + MACCS + контекст эксперимента.
- CV по каркасам, масштабный коэффициент `c ≤ 3`.
- Публичный LB: **1 661 893.99**.

### Анализ ошибки
- Одно обучающее соединение (SI ≈ 36 067) доминирует ~95% общей MSE.
- 13 соединений с SI ≥ 500 дают ~89% оставшегося квадрата ошибки.
- Три тестовых соединения — эпимеры главных рекордсменов обучения. Стандартные Morgan-отпечатки считают их идентичными.

### Модель v2
- Отдельный скрипт (`train_v2.py`), пишущий только в `outputs_v2/` (v1 не трогается).
- Случайная CV вместо CV по каркасам.
- Более широкий поиск масштабного коэффициента `c ∈ [1, 8]` по обрезанной MSE (99.7-й процентиль).
- Поправка по аналогу (сдвиг к SI ближайшего соседа в обучении, `w_max = 0.4`, автоматически отключается при ухудшении CV > 1%).
- Три варианта submission для абляции.
- Публичный LB: **1 536 206.96** (−125 687 ≈ 7.6%).

### Интерпретация улучшения
Прирост согласуется с лучшим глобальным масштабом и скромным вкладом поправки по аналогам. Большой скачок (сотни тысяч) потребовал бы, чтобы поправка сильно подняла прогноз главного «близнеца» к истинному экстремальному SI; по величине улучшения этого не произошло. Большая часть разрыва до топ-10 по-прежнему сосредоточена в одном-двух экстремальных значениях SI.

## Заметки по воспроизводимости
- Все сиды зафиксированы.
- Молекулы из тестового набора по умолчанию удаляются из внешних данных.
- Явная защита юнит-тестами от случайного использования скрытых меток теста (`CC50_uM`, `IC50_uM_VACV`).
- Fallback-режим позволяет полностью проверить пайплайн без RDKit и интернета.
