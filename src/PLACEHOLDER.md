# Исходный код

Сюда нужно положить рабочие файлы реализации:

- `collect_data.py` — устойчивый загрузчик ChEMBL / PubChem с кэшированием, таймаутами и фильтрами по типам активностей
- `validate_data.py` — очистка, расчёт SI, удаление пересечения с тестовым набором
- `features.py` — Morgan / MACCS / дескрипторы RDKit + контекст эксперимента
- `train.py` — исходный пайплайн v1
- `train_v2.py` — финальный рекомендуемый пайплайн (случайная CV, расширенный поиск масштаба, поправка по аналогам)
- `utils.py` — сиды, обрезанные метрики, общие хелперы

Исходный проект (vacv-si.zip) уже содержит рабочую реализацию, которая прошла все тесты и дала указанные баллы на Kaggle. Просто скопируйте папки `src/` и `tests/` из того архива в этот репозиторий.

После копирования команды из основного README будут работать.
